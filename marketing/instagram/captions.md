# Reels placement — paid ads

`out/reels-ads/` — three 1080×1920 stills. These are **ad creative, not organic
posts**: a static image can only reach the Reels surface as a paid placement.
Organic Reels have to be video.

Everything sits in the band between 14% and 65% of the frame height, which is
what Instagram leaves uncovered by its own UI on a Reels ad. The empty lower
third is deliberate — that's where the profile name, caption and CTA button land.

**Objective:** Meta's *App Installs* objective only supports iOS and Android apps,
so it isn't available for a Mac App Store app. Run these as **Traffic** (or
Conversions, if you're tracking site events) with the destination set to either
`deepflowfocus.com` or the App Store URL.

Ad copy uses different fields than an organic caption — no hashtags, and the
primary text truncates early in Reels, so the first line carries the message.

### Reel ad 1 · `reel-1-menu-bar-timer.png` — the free hook

- **Primary text:** A focus timer that lives in your Mac menu bar. One click to start — no window, no Dock icon, no account to make. The timer and stopwatch are free forever.
- **Headline:** Focus from your menu bar
- **Description:** Free · macOS 13+
- **CTA button:** Download

### Reel ad 2 · `reel-2-dont-break-the-chain.png` — the habit

- **Primary text:** Every focus session you finish fills a square. Miss a day and there's a gap you can see. No streak-or-die notifications, no gamified noise — just a record of the reps you put in.
- **Headline:** Don't break the chain
- **Description:** Focus habit tracker for Mac
- **CTA button:** Learn more

### Reel ad 3 · `reel-3-focus-stats-pro.png` — the conversion

- **Primary text:** Streaks, daily goals, session tags, automatic breaks and full history you can export. All on-device — no account, no servers. Deepflow Pro from $1.50/month, or $34.99 once.
- **Headline:** Deepflow Pro
- **Description:** From $1.50/mo · lifetime $34.99
- **CTA button:** Download

### Alternative primary text — clarity-first variants

The three above lead with a hook. These two lead with **what the app actually is**,
for cold audiences who have never seen Deepflow. Meta truncates primary text after
a line or two, so the first sentence carries the whole message. Rotate them against
the originals in the same ad set and let cost-per-landing-page-view decide.

**Variant A · plainest statement**

> Deepflow is a focus timer that lives in your Mac's menu bar. Click the icon, pick a session length, and start — the countdown runs in the bar while you work, and every session logs itself. No Dock icon, no window to manage, no account, and nothing leaves your Mac. The timer and stopwatch are free forever; Pro adds the activity grid, streaks, goals and full history.

**Variant B · problem first**

> Most focus apps want more attention than the work does. Deepflow is the opposite: a timer that lives in your Mac menu bar, starts in one click, and gets out of the way. Every session logs itself automatically — and with Pro, each one fills a square in a year-long grid, so consistency becomes something you can see instead of guess at. Free on the Mac App Store.

Both pair with **Headline:** Focus timer for your Mac menu bar · **CTA:** Download.

Note on tier accuracy: the activity grid, streaks and history are Pro, not free —
both variants keep that line clear rather than implying the grid ships with the
free timer.

For cold traffic, start with ad 1. "Free, one click, lives in your menu bar" is a
far easier first ask than a $34.99 tier.

## Working files

| | |
|---|---|
| `*.dc.html` | the twelve artboards — edit these, then re-run the builders |
| `brand.mjs` | shared brand tokens, grid generator and UI fragments |
| `build.mjs` | the nine 4:5 feed artboards |
| `build-reels.mjs` | the three 9:16 Reels artboards (run after `build.mjs`) |
| `canvas.json` | canvas layout |
| `img/` | embedded assets, all downsampled from `docs/uploads` and `docs/assets` |
| `preview.mjs` | rebuilds `.preview/` for local browser rendering |
| `out/` | 1080×1350 PNGs to post |
| `out/reels-ads/` | 1080×1920 PNGs for the Reels ad placement |

Re-export the PNGs after an edit:

```sh
node build.mjs && node build-reels.mjs && node preview.mjs
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
for f in .preview/*.html; do n=$(basename "$f" .html); \
  "$CHROME" --headless --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1080,1350 --virtual-time-budget=5000 \  # 1080,1920 for the reels
  --screenshot=".preview/shots/$n.png" "file://$PWD/$f"; done
```
